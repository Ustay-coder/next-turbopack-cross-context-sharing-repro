# Results

- `canary.json`: machine-readable three-run factorial result.
- `canary.md`: compact human-readable result.
- `<platform>-<arch>.json`: immutable platform-specific copy of the machine-readable result.
- `<platform>-<arch>.md`: immutable platform-specific copy of the human-readable result.
- `runtime-verification.json`: generated by `pnpm verify`.

Per-cell results and command logs are ignored because they may contain local absolute paths. The committed summaries contain only normalized paths and structured environment data.
